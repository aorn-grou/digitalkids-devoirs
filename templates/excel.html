⬆ Importer un fichier

  1. Téléchargez les fiches de présence (à gauche) : c'est le modèle.
  2. Dans Excel, écrivez les noms des élèves de chaque cours (une ligne par élève) et, si vous voulez, P / R / A sous les dates.
  3. Enregistrez, puis choisissez le fichier ici.

Les nouveaux élèves reçoivent automatiquement leur identifiant et leur code. Un élève déjà inscrit n'est pas créé deux fois.
